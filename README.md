# fiddin-yusfida.github.io

Website akademik Fiddin Yusfida yang dipublikasikan melalui GitHub Pages.

## Memperbarui Konten

Edit `content.js` untuk mengubah identitas, fokus keahlian, proyek, pengajaran, publikasi, dan tautan. Struktur serta desain berada di `index.html` dan `styles.css`.

## Menjalankan Lokal

Buka `index.html` langsung di browser atau jalankan server statis pilihan Anda.

## Publikasi

Repository harus bernama persis `fiddin-yusfida.github.io`. Setelah didorong ke GitHub, situs tersedia di <https://fiddin-yusfida.github.io>.
